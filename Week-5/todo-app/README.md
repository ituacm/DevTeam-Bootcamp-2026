# Todo App

React + Vite todo list: add, toggle, delete, and load sample todos from a dummy API.

Make sure you've installed Node and npm.

## Run

```bash
npm install
npm run dev
```

## Homework

- Filter tabs: all / active / done
- Keep the todos in `localStorage` so they survive a refresh
- Edit a todo
- Search bar (plus: learn and apply debouncing)
